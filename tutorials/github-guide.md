# GitHub QuickStart Guide for Everyone

Welcome to InkuA! This guide is designed for **everyone**—you do not need to be a programmer or computer expert to contribute.

## 1. What is GitHub?

Think of GitHub as a shared online workspace, like Google Drive or Dropbox, but built for managing versions of files.
*   It allows us to work on the same files without overwriting each other's work.
*   It keeps a history of every change, so we can always go back if something goes wrong.

## 2. Getting Started (No Installation Required)

### Step 1: Create a GitHub Account
1.  Go to [github.com](https://github.com/).
2.  Sign up for a free account.
3.  Confirm your email address.

## 3. How to Contribute Using the Website
You can do almost everything directly in your web browser, just like editing a document online.

### Editing a File
1.  Navigate to the file you want to change on GitHub.
2.  Click the **Pencil icon** (✏️) in the top right corner of the file view.
3.  Make your changes in the text editor.
4.  Scroll down to the "Commit changes" box.
5.  Write a short description of what you changed (e.g., "Corrected spelling in introduction").
6.  Select **"Create a new branch for this commit and start a pull request"**.
7.  Click **"Propose changes"**.

### Uploading a New File
1.  Go to the folder where you want to add a file.
2.  Click the **"Add file"** button (top right) and select **"Upload files"**.
3.  Drag and drop your file (Word docs, PDFs, images, etc.) or click to select them.
4.  Scroll down to "Commit changes".
5.  Write a description (e.g., "Added meeting minutes for June").
6.  Select **"Create a new branch..."** and click **"Propose changes"**.

### Submitting Your Changes (Pull Request)
After you propose changes, you will be taken to a "Open a Pull Request" page.
1.  Review your title and description.
2.  Click **"Create pull request"**.
3.  That's it! A team member will review your contribution and merge it.

## 4. For Desktop Users (Optional)

If you prefer working on your own computer instead of the website, **GitHub Desktop** is the easiest way. It gives you buttons to click instead of typing commands.

*   **Download**: [desktop.github.com](https://desktop.github.com/)
*   **How it works**:
    1.  **Clone**: Downloads the project to your computer.
    2.  **Open in External Editor**: Opens files in your favorite program (Word, Notepad, etc.).
    3.  **Commit**: Saves your changes locally.
    4.  **Push**: Uploads your changes to GitHub.

## 5. For Developers & Advanced Users

If you are a developer or want to use advanced tools, here is the setup for you.

### Command Line & VS Code
*   **Git**: [Install Git](https://git-scm.com/downloads) for command-line control.
*   **VS Code**: The recommended code editor. It has built-in Source Control features.

### AI & Collaboration Tools
To boost your productivity, you can integrate AI tools into your workflow:
*   **GitHub Copilot**: AI coding assistant directly in VS Code.
*   **Local AI Models**: Run models like Llama 3 using [Ollama](https://ollama.com/) or [GPT4All](https://gpt4all.io/) for offline assistance.
*   **CLI Assistants**: Tools like `gh` (GitHub CLI) or AI wrappers can automate tasks directly from the terminal.
